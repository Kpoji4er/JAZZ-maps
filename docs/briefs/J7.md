# Бриф: J7 — Изумрудный берег

Снимок: 26 июля 2026. Карта уже на диске; сессия конвейера — довести обвязку и F3-пробелы.

## Идентификация

| Поле | Значение |
|------|----------|
| `sectorId` | `J7` |
| Display | Изумрудный берег / loc `T(468789385226, "Emerald Coast")` |
| Роль | Квестовая сцена `RescueHerMan` + setpiece `EncounterHerman` |
| `mapName` | `qJApdx` → `Maps/qJApdx/` |

## Соседи / travel (данные сектора)

| Направление | Сосед | Road J7 | BlockTravel J7 | Entrance на карте |
|-------------|-------|---------|----------------|-------------------|
| West | I7 (форт) | да | открыто | да (`West`) |
| North | J6 | нет | открыто | да (`North`) |
| East | J8 (море) | нет | **блок** | нет |
| South | — | нет | **блок** | нет |

Замечание: у I7 `BlockTravel.East = true` и нет дороги на East — вход с форта на J7 односторонне затруднён; основной подход — с севера (J6) и выход на запад к I7.

## Враги

- `InitialSquads` / patrol / strong / extra на секторе: **нет** (намеренно).
- Бой и сцена — map UnitMarkers: группы `HermanRaiders`, `RaiderActor01`…`05`, `SceneShooter`, `Herman` / `HermanShaking`.
- Не добавлять гарнизон `InitialSquads` без продуктового решения: риск двойного спавна с квестовыми маркерами.

## Квесты / диалоги

- `RescueHerMan` — основной; badges/refs на I5 и J7.
- Setpiece `EncounterHerman` + conversation `Herman_1` на маркерах.
- Связанные: `TakeTheFortress` (J7 в refs).

## Картинки

- Кастомного `Mod/FhNNYd/Images/...` для J7 нет.

## Маркеры setpiece (уже на карте)

Имена Pos, которые ждёт `EncounterHerman`:

- `HermanShacking`, `HermansFeet`, `Shooter_01`
- `RaiderActor01` … `RaiderActor05`
- Groups: `Herman`, `HermanShaking`, `SceneShooter`, `HermanRaiders`

Известная опечатка vanilla-стиля: Pos `HermanShacking` vs group `HermanShaking` — не переименовывать без правки setpiece.

## Чеклист F3 (владелец)

1. Открыть карту `qJApdx` (F5 → J7 / mapName).
2. Проверить BorderArea и проходимость к Entrance **West** и **North**.
3. Сверить все Pos setpiece выше: Place/имя совпадают с setpiece; Map setpiece = `qJApdx`.
4. UnitMarkers Herman/Raiders: Spawn/Despawn conditions осмысленны для `RescueHerMan` (не только `04_Betrayal` worldflip).
5. Loot/ContainerMarker на берегу — по желанию, не блокирует квест.
6. Deployment/player start при входе с North и West — зоны не в минах StartingMinefield.
7. Save map. Затем Reload мода, если агент уже правил `items.lua`.

## Критерий «готово»

- Вход с North (J6) и выход/вход West (связь с I7 по правилам BlockTravel).
- Квест `RescueHerMan` запускает/продолжает сцену на J7; setpiece без чёрного экрана.
- На сателлите сектор читается как часть Эрни (`Label1=Ernie`, `WeatherZone=Erny`).
- Нет лишнего `InitialSquads`-гарнизона поверх квестовых рейдеров.

## Smoke (владелец в игре)

1. Reload / Save mod после обвязки.
2. Новая игра или сейв с доступом к Эрни → на сателлите J7 с Label Ernie.
3. Войти в J7 с **North** (из J6): deployment не в минах; карта `qJApdx`.
4. Выйти на **West** к I7 (если BlockTravel I7 позволяет обратный заход — отдельно).
5. Пройти/триггернуть `RescueHerMan` → setpiece `EncounterHerman` без чёрного экрана.
6. Убедиться, что нет лишнего satellite-гарнизона поверх рейдеров на карте.
